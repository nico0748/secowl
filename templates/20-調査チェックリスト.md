# 診断チェックリスト — {{title}}

> OWASP WSTG v4.2 と OWASP Top 10:2025 に沿った実行チェックリストです。
> 全項目を「検証済み」にすることが網羅性の担保です。チェックは「検証した」という意味で、「安全だった」という意味ではありません。
> 検出があった項目はトリアージで発見事項個票を起票します。検出しなかった項目は `20-調査/未検出記録.md` に根拠を書きます。

## 進める順序

境界を固める順に進めます。A02 と A04 は偵察の続きとしてすぐ終わります。
A01 で認証・セッション・認可の境界を固めてから、入力点ごとに A05 を網羅します。

## A02 セキュリティの設定ミス

- [ ] 詳細エラー・スタックトレース・デバッグモードの露出
- [ ] ディレクトリリスティング
- [ ] .git / .env / .bak / ~ などのバックアップ・設定ファイルの露出
- [ ] 管理コンソール・/actuator などの管理エンドポイントの無認証公開
- [ ] デフォルト認証情報
- [ ] セキュリティヘッダの欠落（CSP / HSTS / X-Frame-Options / X-Content-Type-Options / Referrer-Policy）
- [ ] 過剰な CORS（`*` と credentials の併用）
- [ ] 不要な HTTP メソッド（TRACE / OPTIONS / PUT）
- [ ] robots.txt / sitemap.xml / .well-known からの情報漏えい

## A04 暗号化の失敗

- [ ] TLS バージョン（1.0 / 1.1 の有効性）と弱い暗号スイート
- [ ] 証明書の有効期限・CN/SAN の不一致・自己署名
- [ ] HSTS の有無と HTTP から HTTPS へのリダイレクト
- [ ] 混在コンテンツ（mixed content）
- [ ] URL・ログへのトークンや個人情報の露出

## A03 サプライチェーンの失敗

- [ ] CMS / フレームワーク / ライブラリのバージョン特定と既知 CVE の照合
- [ ] 読み込んでいる JS ライブラリの古いバージョン
- [ ] 外部 CDN・サードパーティスクリプトの SRI 欠如

## A01 アクセス制御の不備（SSRF を含む）

- [ ] 水平越境（IDOR）: id / uuid / ファイル名を他ユーザの値へ差し替え
- [ ] 垂直越境: 一般権限で /admin/* や /api/internal/* へ到達できるか
- [ ] 強制ブラウジング: 未リンクの管理画面・旧 API・バックアップ
- [ ] メソッド改変: GET から PUT・DELETE へ、X-HTTP-Method-Override
- [ ] SSRF: URL 取得・Webhook・画像/PDF 生成での内部フェッチ
- [ ] ディレクトリトラバーサル / LFI
- [ ] マルチテナント越境

## A07 認証の失敗

- [ ] ユーザ列挙（ログイン・リセット・登録の応答差とタイミング差）
- [ ] パスワードポリシーとアカウントロックの挙動確認（大量試行は行わない）
- [ ] パスワードリセットトークンの推測可能性と有効期限
- [ ] Cookie 属性（Secure / HttpOnly / SameSite）
- [ ] セッションの再生成・ログアウト後の無効化・タイムアウト・セッション固定
- [ ] JWT（alg:none / 署名検証不備 / 弱い鍵）

## A05 インジェクション

- [ ] 反射型 XSS（出力コンテキスト別: HTML 本文 / 属性 / JS / URL）
- [ ] 格納型 XSS
- [ ] DOM ベース XSS（sink: innerHTML / document.write / eval）
- [ ] SQLi（エラー / UNION / ブラインド。ヘッダ・Cookie・JSON も対象）
- [ ] コマンドインジェクション（時間遅延で無害に確認）
- [ ] SSTI（`{{7*7}}` が 49 になるか）
- [ ] XXE / NoSQL / LDAP / ヘッダ注入
- [ ] プロンプトインジェクション（LLM 連携機能がある場合）

## A06 安全でない設計・ビジネスロジック

- [ ] 重要操作の再認証・確認の欠如
- [ ] アンチオートメーション（CAPTCHA / throttle）の欠如
- [ ] ステップスキップ・状態遷移の不正
- [ ] 価格・数量・割引の改ざん / 負数・上限バイパス
- [ ] レースコンディション（在庫・残高の二重消費）
- [ ] レート制限なしのリソース消費

## A10 例外処理の不備

- [ ] 境界・異常入力（巨大値 / 負数 / null / 型不一致）で 500 や内部情報の露出
- [ ] 404 / 500 ページでの内部パス・製品バージョンの露出
- [ ] フェイルオープン（エラー時に認可が緩む）

## A08 整合性の不具合

- [ ] クライアント値（hidden / Cookie / JWT）を無条件に信頼していないか
- [ ] 安全でないデシリアライゼーションの受理点

## A09 ログ・監視の失敗

- [ ] 異常アクセスに対する検知・遮断の有無
- [ ] エラー画面などに機微情報が記録・表示されていないか

## 横断項目

- [ ] CSRF（状態変更操作のトークン検証・SameSite・再認証）
- [ ] オープンリダイレクト
- [ ] クリックジャッキング
- [ ] ファイルアップロード（拡張子 / MIME / マジックバイト / 保存先の実行可否）
- [ ] ダウンロード・パストラバーサル
- [ ] HTTP リクエストスマグリングなどのプロトコル層

## STRIDE による抜け漏れ点検

調査の終盤で、6 つの観点に空白がないかを確かめます。

- [ ] Spoofing なりすまし → A07 / セッション / JWT
- [ ] Tampering 改ざん → A08 / クライアント値の信頼
- [ ] Repudiation 否認 → A09
- [ ] Information Disclosure 情報漏えい → A02 / A04
- [ ] Denial of Service サービス妨害 → A06（負荷試験は行わない）
- [ ] Elevation of Privilege 権限昇格 → A01
