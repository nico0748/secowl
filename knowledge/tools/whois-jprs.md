## 機能

`.jp` ドメインの登録者・管理担当者・ネームサーバ・登録年月日を引けます。gTLD の WHOIS は GDPR 以降ほとんど秘匿されていますが、`.jp` の組織種別ドメイン（`co.jp` など）は**登録組織名が公開されたまま**です。これが日本国内の資産調査で効きます。

## 使いどころ

- 対象組織が実際にそのドメインを保有しているかの確認（スコープの裏取り）
- `co.jp` は 1 組織 1 ドメインの原則があるため、組織の正規ドメインを特定しやすい
- 登録年月日と有効期限から、放置されたドメインを見つける

## 使い方

```bash
whois -h whois.jprs.jp example.co.jp

# 日本語の登録者名を取る場合
whois -h whois.jprs.jp "example.co.jp/j"
```

ブラウザからは <https://whois.jprs.jp/> で検索します。

## 読みどころ

| 項目 | 何が分かるか |
|---|---|
| Registrant（登録者名） | 保有組織。スコープの確認に使う |
| Name Server | DNS の委任先。外部サービスに委任していれば、その事業者も調査範囲に関わる |
| 登録年月日 / 有効期限 | 失効間近のドメインは乗っ取りの候補になる |
| 状態 | `Active` 以外（`Suspended` など）は運用が止まっている可能性 |

## 注意点

JPRS の WHOIS は大量照会を禁じています。自動化する場合は間隔を空け、取得した個人情報は診断の目的以外に使わないでください。
