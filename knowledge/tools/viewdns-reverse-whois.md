## 機能

組織名やメールアドレスから、**その登録者が保有する他のドメインを逆引き**します。1 つのドメインしか知らされていない状態から、同じ組織が持つ資産の全体像へ広げるときに使います。

| 機能 | 用途 |
|---|---|
| Reverse Whois Lookup | 登録者名・メールから保有ドメインを引く |
| Reverse IP Lookup | 同一 IP に同居しているドメインを引く（共用ホスティングの発見） |
| Reverse NS Lookup | 同じネームサーバを使うドメインを引く |
| DNS Report | レコードの設定不備をまとめて見る |
| Port Scanner | 代表的なポートの開閉（軽量な確認用） |

## 使いどころ

- スコープの確定前: 顧客が把握していないドメインを洗い出し、RoE の対象に含めるか相談する
- 買収や分社でドメインが分散している組織の棚卸し
- Reverse IP で、診断対象と同じサーバに別組織のサイトが同居していないかの確認（**同居していれば、そのサーバへの負荷試験は他者に影響します**）

## 注意点

- 無償版は 1 日あたりの回数制限があり、結果も全件ではありません。見つかったものは「ある」の証拠になりますが、見つからないことは「ない」の証拠になりません
- 逆引きで出たドメインは、顧客の資産とは限りません。**RoE に明記されていないドメインへは一切アクセスしない**でください
