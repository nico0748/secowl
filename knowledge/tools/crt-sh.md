## 機能

公開されている証明書透明性（Certificate Transparency）ログを検索します。**公開された証明書はすべてログに載る**ため、過去に証明書を取ったことがあるホスト名は、外部から到達できなくてもここに残ります。パッシブ偵察で最も当たりの多い情報源です。

## 使い方

```bash
# JSON で取り、重複を除いてホスト名の一覧にする
curl -s 'https://crt.sh/?q=%25.example.com&output=json' \
  | jq -r '.[].name_value' | sed 's/\*\.//' | sort -u

# 組織名で引く（証明書の Organization フィールド）
curl -s 'https://crt.sh/?O=Example+Inc&output=json' | jq -r '.[].common_name' | sort -u
```

ワイルドカードの `%` は URL エンコードして `%25` と書きます。

## 読みどころ

- `*.example.com` のワイルドカード証明書しか出ない場合、個別のホスト名は隠れています。別の情報源と併用してください
- 有効期限が切れた証明書に出てくるホスト名は、**使われなくなった環境**を指すことがあります。ステージングや旧システムが残っていないかを確認します
- 証明書の発行日が集中している時期は、環境の構築時期を示します

## 注意点

ここで出たホスト名は過去の記録です。現在も生きているかは `dnsx` や `httpx` で確認してから、サーフェスとして登録してください。
